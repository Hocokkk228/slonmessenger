# SLON — свой сервер за 0 ₽

Это тот же сервер, что крутится на Cloudflare, но собранный в **один Node-процесс**.
Он держит аккаунты, сообщения, звонки, шифрование — **и сам раздаёт сайт**. То есть
и фронт, и бэкенд живут на одном адресе, ничего чужого (ни GitHub, ни Cloudflare) не нужно.

Смысл: запускаешь на **любой всегда-включённой машине** — хоть на домашнем компе — и платишь
**ноль**. Если это машина в России, другие россияне достают её **без VPN** (вы в одной стране).

## Что нужно
- **Node.js 22.5 или новее** (нужен встроенный `node:sqlite`). Проверить: `node --version`.
- Больше ничего. Никаких сборок, никакого Python, база — обычный файл.

## Запуск (3 команды)
```bash
cd server/node
npm install            # ставит только ws, за секунду
node server.js
```
Всё. Сервер поднялся на `http://localhost:8080`. Открой этот адрес в браузере — это уже SLON.
База лежит рядом в `slon.db` (один файл — это вся переписка и аккаунты, его и бэкапить).

Настройки (порт, TURN, пуши) — по желанию, см. `.env.example`. Без них тоже работает.

## Чтобы дошло с телефонов и до других людей
Телефону/собеседнику нужен **адрес, который виден снаружи**, и **HTTPS** (браузеры без него
не пускают камеру, микрофон и уведомления). Самый простой бесплатный способ — поставить
перед сервером **Caddy**: он сам берёт бесплатный сертификат и проксирует на наш порт.

1. Заведи бесплатный домен (например, динамический DNS) и направь его на IP машины.
   Дома — пробрось порт 443 на этот комп в настройках роутера.
2. Поставь Caddy и создай `Caddyfile`:
   ```
   твой-домен.ру {
       reverse_proxy localhost:8080
   }
   ```
3. `caddy run` — через минуту сайт открывается по `https://твой-домен.ру`, уже с сертификатом.

Открой этот адрес в приложении — оно **само** поймёт, что сервер тут же, и будет ходить сюда,
а не на Cloudflare (адрес API вычисляется из адреса сайта). Проверить/переопределить вручную:
в консоли браузера `localStorage.setItem('sl_api', JSON.stringify('https://твой-домен.ру'))`.

### Подводные камни, честно
- Комп должен быть **включён**, пока кем-то нужен сервер. Уснул — связи нет.
- Некоторые домашние провайдеры прячут тебя за общим IP (CGNAT) — тогда проброс порта не
  сработает. Признак: во «внешнем IP» роутера и на `2ip.ru` разные адреса. Лечится только
  сменой тарифа/провайдера или чужой машиной с белым IP.
- Держать сервер живым между перезапусками — через systemd (пример ниже).

## Как автозапуск (Linux, systemd)
`/etc/systemd/system/slon.service`:
```ini
[Unit]
Description=SLON server
After=network.target

[Service]
WorkingDirectory=/путь/к/slonmessenger/server/node
ExecStart=/usr/bin/node server.js
Restart=always
Environment=PORT=8080
Environment=DATA_DIR=/var/lib/slon

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now slon
```

## Перенос данных с Cloudflare (по желанию)
Новые аккаунты и переписка сразу живут здесь. Старые аккаунты с Firebase переносятся сами
при первом входе (пока `FB_MIGRATE=1` и Firebase доступен). Отдельный экспорт истории из D1
не нужен — журнал у каждого устройства и так синкается заново с нового сервера.
